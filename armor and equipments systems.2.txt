137. ARMOR SET SYSTEM OVERVIEW

Armor sets provide long-term collection goals while adding additional identity to equipment.

A complete armor set provides a small bonus.

The purpose is:

Encourage collecting
Create visual identity
Reward completion

The purpose is not to create stronger players.

137.1 ARMOR SET PHILOSOPHY

Armor sets follow:

Collection > Power

Completing a set should feel rewarding.

However:

A skilled player with incomplete armor should still compete.
