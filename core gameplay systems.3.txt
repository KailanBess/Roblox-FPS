53. WEAPON SYSTEM OVERVIEW

Weapons are the primary gameplay expression system.

The weapon ecosystem is designed around:

Different playstyles
Clear strengths and weaknesses
Skill expression
Balanced competitive choices

The goal is not:

"One strongest weapon."

The goal is:

"Many weapons with different reasons to exist."

53.1 Weapon Design Philosophy

Every weapon must answer:

Who is this weapon for?
What range does it dominate?
What weakness balances it?
What skill does it reward?

Example:

A sniper is not balanced because it does low damage.

A sniper is balanced because:

It requires precision
It sacrifices close-range flexibility
It punishes mistakes

55. ASSAULT RIFLE CLASS
Purpose

General-purpose primary weapons.

Designed for:

Mid-range fights
Flexible positioning
Consistent performance
Strengths
Balanced damage
Good range
Reliable accuracy
Adaptability
Weaknesses
Not strongest in any single category
Requires consistent aim
Design Goal

Assault rifles should be the default competitive foundation.

56. SMG CLASS
Purpose

Close-range aggressive weapons.

Designed for:

Fast movement
Entry fights
Flanking
Strengths
High mobility
Fast handling
Strong close-range DPS
Weaknesses
Poor range
Lower armor effectiveness
Reduced long-distance accuracy
Design Goal

SMGs reward aggressive players.

57. SHOTGUN CLASS
Purpose

Close-range burst weapons.

Strengths
Extreme close-range power
Area control
Punishes poor positioning
Weaknesses
Limited range
Requires commitment
Design Goal

Shotguns should dominate rooms, not entire maps.

58. SNIPER CLASS
Purpose

Long-range precision.

Strengths
High damage
Precision advantage
Long-range control
Weaknesses
Slow handling
Requires accuracy
Vulnerable to pressure
Design Goal

Snipers reward patience and precision.

59. PISTOL CLASS
Purpose

Secondary weapons.

Strengths
Fast swap speed
Emergency combat
High mobility
Weaknesses
Limited range
Lower sustained damage
Design Goal

Pistols should be useful, not disposable.

60. LMG CLASS
Purpose

Sustained fire weapons.

Strengths
Large magazines
Suppression
Extended fights
Weaknesses
Slow handling
Lower mobility
Design Goal

LMGs reward positioning.

61. MARKSMAN CLASS
Purpose

Precision semi-automatic weapons.

Strengths
Accuracy
Range
Controlled damage
Weaknesses
Requires precision

Design Goal

Marksman weapons reward accuracy.

62. KNIFE CLASS
Purpose

Melee option.

Strengths

Every weapon uses standardized statistics.

Fire Rate

Rounds per minute.

Formula:

RPM =
Shots fired per minute

Accuracy

±25%

74. FUTURE WEAPON EXPANSION RULES

New weapons must:

Not be:

"Better versions."

They must be:

"Different options."

Example:

New AR:

Cannot simply be:

Higher damage + higher fire rate + better accuracy.

Instead:

High damage but slower.

OR

High accuracy but lower DPS.
