36. MOVEMENT SYSTEM

Movement is one of the primary skill expressions in the FPS ecosystem.

Movement should reward:

Mechanical skill
Positioning
Timing
Map knowledge

Movement should not create:

Unavoidable advantages
Extreme speed abuse
Random combat outcomes
36.1 Movement Constants
MAX MOVEMENT SPEED = 250

MIN MOVEMENT SPEED = 190

Every playable loadout must exist inside this range.

36.2 Movement Philosophy

Movement is designed around:

Mobility vs Accuracy

Fast players gain:

Better positioning
Faster rotations
Aggressive opportunities

But lose:

Precision
Stability
36.3 Movement States

Players can exist in:

Idle

Walking

Running

Sprinting

Jumping

Crouching

Sliding

ADS Movement

Each state affects:

Accuracy
Weapon handling
Visibility
Mobility
37. SPRINT SYSTEM

Sprint allows fast repositioning.

Sprint provides:

Increased movement speed
Faster map traversal

Sprint reduces:

Immediate combat readiness
37.1 Sprint Rules

While sprinting:

Cannot:

Fire immediately at full accuracy

Requires:

Sprint-to-fire transition time
37.2 Sprint-to-Fire

Every weapon has:

Sprint Out Time

Example:

SMG:

Fast sprint recovery

LMG:

Slow sprint recovery

38. CROUCH SYSTEM

Crouching provides:

Benefits:

Lower profile
Reduced movement noise
Better stability

Tradeoff:

Reduced mobility.

39. JUMP SYSTEM

Jumping exists for mobility.

Jumping should not become:

Bunny hopping abuse
Perfect accuracy movement

While airborne:

Effects:

Increased bloom
Reduced accuracy
40. SLIDE SYSTEM

Sliding is optional movement tech.

Purpose:

Aggressive repositioning
Momentum control

Slide rules:

Limited duration
Requires sprint momentum
Accuracy penalty
41. MOVEMENT BALANCE RULES

Movement cannot:

Ignore weapon weaknesses
Create impossible tracking situations
Remove tactical positioning

Movement skill should improve:

Survival
Positioning

Not:

Damage output

Recoil patterns

48. WEAPON HANDLING SYSTEM

Weapons are balanced using more than damage.

Every weapon includes handling statistics.

48.1 Handling Stats
Equip Speed

Time to pull weapon out.

Swap Speed

Time between weapons.

ADS Speed

Time to aim.

Sprint Out Time

Time from sprinting to firing.

First Shot Accuracy

Accuracy of first bullet.

Bloom Growth

How quickly accuracy decreases.

Bloom Recovery

How quickly accuracy returns.

ADS Stability

How steady scoped weapons remain.

Flinch Resistance

How much incoming damage affects aim.
