# 3. ARMOR SYSTEM

Armor does not add HP.

Armor provides damage reduction.

Formula:

```
Armor Reduction =
(Armor / 150) × 30%
```

Example:

```
150 Armor = 30% reduction
75 Armor = 15% reduction
```

---

# 4. DAMAGE SYSTEM

```
Final Damage =

Base Damage
× Upgrade Modifier
× Headshot Modifier
× Armor Modifier
× Movement Modifier

× (1 - Armor Reduction)
```

TTK:

```
Shots To Kill =
Ceiling(Target HP / Damage)
```

```
TTK =
(Shots To Kill - 1)
×
(60 / Fire Rate RPM)
```
